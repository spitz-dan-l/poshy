Review Notes

Carry this model into phase 6 instead of reviving catalog-owned optimizer metadata.
Why this lives here

The player experiences planning from the workbench side, so liquidation policy belongs with goals and preview output, not in GM/admin setup tabs.

How later screens use it

The mixed plan consumes the approved Leather Shoes sale. The ingredient-funding example consumes only the surplus left above keep floors and pinned reserves.

Persistence model

These rules are per-run planner state. They should reset with Reset Run and Seed From Base, and they should not create history entries.
